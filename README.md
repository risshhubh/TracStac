# TracStac 🚀

TracStac is a premium project management application built with Next.js 15, TypeScript, Tailwind CSS 4, and Prisma.

## ✨ Features
- **Premium UI**: Glassmorphic design with a sleek dark mode.
- **Project Management**: Create projects, assign tasks, and track progress.
- **Role-Based Access**: Support for Admin and Member roles.
- **Pulse Dashboard**: Visual stats and recent activity tracking.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS 4
- **Database**: SQLite (via Prisma)
- **Icons**: Emoji-based (for speed)
- **Components**: Custom premium UI library

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Setup Database**:
   ```bash
   npx prisma db push
   npx tsx prisma/seed.ts
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) to see your premium dashboard!
